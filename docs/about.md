# 关于与维护

## 这个库解决什么问题

以中文梳理开放词汇分割论文的研究问题、输入输出、方法和证据。3D 点云是重点，其他模态用于理解不同研究者如何解决相关问题。目标约100篇，采用弹性方向配额，不为凑数引入弱相关文献。

## 收录与阅读状态

1. 优先正式发表在相关重要会议、期刊且方法具有代表性的工作。
2. 非3D方向优先近期、已有实际官方实现、实验设置清楚的工作。预印本单独标记。
3. `已建索引`：核查身份、来源及官方代码公开情况；尚未完整精读。
4. `样例笔记`：按统一模板解释方法与实验，并记录原文版本和证据位置；不代表完成逐行代码核查或复现。

首期涵盖3D、2D、视频、多视角和3DGS；RGB-T、多光谱、音视频、遥感、医学方向将在后续批次扩展。

## 四种证据标签

| 标签 | 含义 |
| --- | --- |
| 【原文事实】 | 在注明版本的论文中读到的方法、结果或限定条件 |
| 【官方文档说明】 | 作者仓库 README 等文档的陈述，未等同实际执行路径 |
| 【代码事实】 | 已实际检查实现及调用链的结论，必须写明路径和符号；本批样例未做此级审计 |
| 【分析推断】 / 【待验证假设】 | 整理者的解释、比较和设想，不能当作作者结论 |

## 开源状态怎么理解

- **已公开实现**：找到了官方仓库中的实际代码与使用入口，不只是占位页面。
- **部分公开**：只有部分步骤，关键实现或依赖缺失时另行说明。
- **计划公开**：官方只承诺将来发布。
- **尚未确认**：本轮没有找到可靠官方实现，不等于断言作者明确不开源。

公开代码、提供权重链接、能下载权重、能运行、能复现论文结果是五件不同的事。本库首轮仅检查前两类材料，尚未独立验证下载与运行。模型依赖和许可条件以原仓库为准。

## 内容如何更新

源笔记位于 `docs/papers/`。一篇论文一份 Markdown，YAML front matter 记录结构化字段；列表、统计、时间线和矩阵由构建脚本生成。技术和数据集使用 `data/taxonomy.yaml` 中的受控标识。

GitHub README 也按研究方向列出所有论文、官方代码与仓库内笔记入口。它与网站共用论文元数据，更新后先同步清单，再构建网站。

新建条目时复制论文模板，将文件名设为稳定 `paper_id`，替换示例来源与字段。身份核查未完成前保持索引状态，不填造未知作者、数据和公式。标题和会议更新时保持 ID 不变；同一工作的预印本和会议版不重复计数。

```bash
.codex_tmp/venv/bin/python scripts/update_readme.py
.codex_tmp/venv/bin/python scripts/build.py --check
```

校验会检查字段、ID、受控标签、关系引用、样例章节和证据来源，再严格构建并检查站内链接。脚本不会自动检查外部链接的实时可用性。

## 部署与本地浏览

推送 `main` 后，GitHub Actions 自动校验并发布 GitHub Pages。PR只校验和构建，不部署。网站地址和本地启动命令见[仓库说明](https://github.com/buzhidaozenmo/Open-Vocabulary-Segmentation-Atlas)。

浏览器全文搜索和组合筛选在客户端运行，无需数据库或账号。JS不可用时论文库保留完整静态索引。筛选条件可从地址栏复制分享。
